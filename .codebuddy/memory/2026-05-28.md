### 18. Bug修复：AI助手模块切换白屏 + 消息提醒不生效
**问题1 - AI助手模块切换白屏**:
- 根因：`BidMatching.vue` 使用了 `reactive()` 但未导入，导致组件运行时报错 `reactive is not defined`，整个页面白屏
- 修复：`import { ref } from 'vue'` → `import { ref, reactive } from 'vue'`

**问题2 - 消息提醒弹窗不显示**:
- 根因：通知弹窗使用 `position: absolute` 定位，但侧边栏 `.sidebar` 设置了 `overflow: hidden`，弹窗被裁剪不可见
- 修复：通知弹窗改为 `position: fixed; bottom: 80px; left: 12px; z-index: 2000`
- 新增 `.notification-backdrop` 透明遮罩层（`position: fixed; inset: 0; z-index: 1999`），点击遮罩关闭通知

**附带修复 - 平台编辑保存提示逻辑**:
- `savePlatform()` 函数中 `editingPlatform.value` 在判断前被置为 null，导致编辑时总是提示"平台已添加"
- 修复：先保存 `const isEdit = !!editingPlatform.value` 再重置
